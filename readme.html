利用規約

UTAU向け音声ライブラリ「花氷クレア」及びそれに付随するキャラクターの使用にあたり、本規約を熟読し、理解、同意したものとします。

○本ライブラリの使用について

1.禁止事項
  • 政治的、宗教的、差別的な内容を含む作品／R18作品／常識、公序良俗に著しく反する表現を含む作品での使用
  • 法令での規制に違反する行為及びそれを促す行為、また特定の個人や企業等に対する侮辱や攻撃に利用すること
  • 無断での商用利用
  • 著作者を偽る行為
  • 本ライブラリデータの再配布
  • 本ライブラリを本キャラクター以外のキャラクターボイスとして利用すること
2.作品の公開、配布、販売
  • 無償での作品公開(連絡は任意)
  • 非営利目的、同人活動の範囲での頒布物への利用(連絡は任意)
  • 商用利用の場合、また商用に当たるか判断がつかない場合は本ページヘッダーに記載の連絡先までご連絡ください。
  • 有償無償に関わらず、本ライブラリを使用した作品を公開、頒布、販売する際は「花氷クレオ」の名前を必ず明記してください
  • 本ライブラリを使用した作品で他のライブラリ及びキャラクターとカップリング扱い等をしたい場合、相手側の利用規約も熟読し、違反のない範囲であれば可能です。
  • 公開された作品は公式HPで紹介させていただく可能性があります。
